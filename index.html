PeJu Finanças

Controle financeiro pessoal na nuvem

Um app web para organizar o dinheiro do mês: lançar gastos em segundos, ver para onde vai o salário e planejar compras parceladas. Nasceu de uma necessidade real e é usado no dia a dia por mim e pela minha família.

  • Importa extratos bancários (OFX e CSV), exporta para Excel e faz backup completo.
  • Testes de ponta a ponta com Playwright, simulando o Firebase localmente.

AutoNF

Emissor de notas fiscais de serviço para Windows

Aplicativo desktop que emite NFS-e no padrão nacional direto na API oficial da Receita (Sefin Nacional), assinando com o certificado digital A1. Fiz para uma psicóloga emitir as notas do mês em poucos cliques, com os dados guardados só no computador dela.

  • Integração com a Sefin Nacional com autenticação mTLS e assinatura digital do XML.
  • Servidor local em Python (Flask) com interface em HTML, CSS e JavaScript, e banco SQLite.
  • Backup criptografado (AES-256-GCM), envio da nota por e-mail e exclusão de dados de paciente seguindo a LGPD.
  • Auditoria de segurança com 15 correções e 175 testes automatizados, 92 deles de ponta a ponta com Playwright.
  • Empacotado como executável com PyInstaller e acompanhado de manual de uso em PDF.
